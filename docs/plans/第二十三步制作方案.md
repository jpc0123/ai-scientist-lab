# 第二十三步制作方案：v2.3 CUDA + Vendor DFINE 正式科研实跑

> **本文档为 Scientist Lab v2.3 权威实现方案。**  
> 基线：`v2.2.0`（封版就绪；tag 待授权）/ 功能冻结参考 `v2.1.0` @ `bb47db0`。  
> 推荐分支：`feat/v2.3-cuda-vendor-dfine`（可自当前工作树切出；当前也可在同分支继续）。  
> **核心原则：** 默认零 GPU / 零网络；真实 CUDA 显式门禁；stand-in 证据不得支撑 formal DFINE Claim；人工审批与安全边界不变。

## 1. 总体目标

补齐：

```text
Vendored D-FINE（pinned）就绪
→ CUDA 镜像 / environment_key 门控
→ Fast Eval（短预算）Vendor 实跑
→ 证据标注非 stand-in
→ Formal triad / Claim Gate 升级路径
→ 可选：多 Seed / 消融 / 验收报告
```

完成后定位：

> 在受控工作台内，可用 CUDA Worker 跑通 **Vendor DFINE** Fast Eval，并诚实区分 exploratory vs formal 证据。

