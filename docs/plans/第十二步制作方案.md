## 6. Claim Gate 规则

- 每条结论可关联 `claim_id` / `support_status` / `evidence_ids` / `limitations`
- 禁止强结论措辞（SOTA / 已证明 / 优于现有方法 / full RGBT-Tiny 等）
- blocked / unsupported 不得写成 moderate/strong
- 弱证据不得支撑 strong 结论

真实 LLM 继续延期。下一步见 `第十三步制作方案.md`（v1.3 Provider 层）。
