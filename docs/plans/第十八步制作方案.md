## 0. 目标

在 v1.7 控制台之上产品化已有 CLI 发布链：

```text
ExperimentTree + Evidence/Claim
→ ResearchReport（build / verify）
→ Audit Bundle（build / verify）
→ ReleasePackage（freeze + tar.gz export）
→（可选）挂接 Patch merge-intent
```

「工作区」三层语义：

| Kind | 含义 | 本版行为 |
|------|------|----------|
| `main` | 主源码树 | **只读元数据**；永不写入 |
| `sandbox` | Patch 沙箱 | 已有；发布时可引用路径 |
| `frozen` | 发布快照元数据 | 记录 git HEAD / 绑定产物；不整树拷贝 |

## 2. 状态机

```text
draft → frozen → exported
              ↘ discarded
```

- `create`：绑定 project / 可选 tree、report、audit、patch_ids  
- `freeze`：写入 snapshot 元数据，`main_workspace_modified=false`  
- `export`：打 tar.gz（v1.8.3）；本版 API 先对齐 audit 目录 export  
- `discard`：终态，不可再导出

---

## 3. API（相对 v1.7 增量）

```text
POST /api/v1/reports/build
POST /api/v1/audits/build
POST /api/v1/audits/{bundle_id}/export
GET  /api/v1/releases
GET  /api/v1/releases/{release_id}
POST /api/v1/releases
POST /api/v1/releases/{release_id}/freeze
POST /api/v1/releases/{release_id}/discard
GET  /api/v1/workspaces/summary
```

权限与状态机仍由后端强制；前端确认 ≠ 授权。

## 4. 安全边界

- `decide-merge` 仍只记意图  
- Patch apply 仅 sandbox  
- Release freeze / export **不得**修改主工作区  
- 无任意 Shell / 无一键 merge 主分支
