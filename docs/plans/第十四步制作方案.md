## 0. 目标

接入统一的 `OpenAICompatibleProvider`（兼容官方 OpenAI、中转站、NewAPI、本地服务），
并保证：

- 默认仍然是 mock
- 离线测试完全不访问网络
- CI 默认不需要 API Key
- 真实调用必须显式启用
- 有预算、超时、重试与并发保护（后续子版本）
- 可生成 Replay，但不得记录密钥和敏感请求头

**不做（延期）：** 流式、Function Calling、多模态、多 Provider 路由、语义缓存、Web 控制台。

## 2. v1.4.1 配置契约

环境变量（仅在选择真实 Provider 时强制）：

```text
LLM_PROVIDER=openai-compatible
LLM_BASE_URL=https://example.com/v1
LLM_API_KEY=...
LLM_MODEL=...
LLM_TIMEOUT_SECONDS=60
```

硬门禁：

- API Key 只从环境变量或显式注入读取
- `repr()` / 日志 / 异常 / usage 报告不得泄漏 Key
- 缺少 Key 时给出明确 `MissingAPIKeyError`
- mock / fake / replay 不检查真实配置
