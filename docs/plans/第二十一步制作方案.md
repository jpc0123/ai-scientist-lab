# 第二十一步制作方案：v2.1 真实 LLM 多轮科研闭环

> **基线：** `v2.0.0`  
> **建议分支：** `feat/v2.1-real-llm-closed-loop`  
> **原则：** 不堆普通工作台功能；证明真实模型能根据实验反馈改变下一轮规划。

## 唯一核心目标

```text
读取第一轮实验结果
→ 分析证据缺口
→ 提出下一实验
→ Critic + 规则审查
→ 人工批准
→ 真实执行
→ 读取新实验结果
→ 改变第二轮规划
```

与「真实 API 调用成功」（v1.4）和「质量评测」（v1.5）不同：v2.1 要证明**模型真正参与反馈迭代**。

## 分阶段

| 子版本 | 内容 |
|--------|------|
| v2.1.1 | 真实 Model Profile + `llm-doctor` + Quality Gate |
| v2.1.2 | Digits 第一轮真实规划（禁 Mock/Replay fallback） |
| v2.1.3 | 真实 Critic → Verifier → 人工审批 |
| v2.1.4 | 真实 Digits 执行 → Evidence / Claim |
| v2.1.5 | 第二轮真实规划须体现第一轮新结果 |

## 验收

- 离线：`scripts/accept_v21.py`（Replay 两轮；CI 零网络）
- 显式真实：`scripts/accept_v21_real.py`（需 `RUN_REAL_LLM_TESTS=1` + `LLM_ALLOW_NETWORK=true`）
- 报告：`outputs/<project_id>/acceptance/v21_real_closed_loop_report.json`

关键字段：`fallback_used=false`、`round_count=2`、`feedback_present_in_round_2_context=true`、`human_approval_preserved=true`。

## 不做

更多 Dashboard / CRUD、第二个云 Provider、多用户、自动 Git Push、复杂权限、更多 Mock 场景。
