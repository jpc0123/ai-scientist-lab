## 4. v2.0 正式能力定义

Scientist Lab v2.0 是一个**本地优先、人工审批驱动、可复现、可恢复、可审计**的 AI Scientist 工作台，支持：

- 实验协议与模型执行
- 多轮有限实验树
- 证据与结论治理（Claim Gate）
- 真实 LLM Provider（可选、门禁）与质量评测
- 报告与 Audit Bundle
- 受限源码补丁与受控 Merge/Rollback
- Web 工作台 / Doctor / Recovery / 安装启动

**不应描述为：** 完全自主 AI 科学家；已完成真实 RGB-T 科研结论；模型可自动改代码并发布；可不经人工持续研究。
