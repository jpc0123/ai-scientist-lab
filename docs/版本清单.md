## 4. v2.1 正式能力定义

Scientist Lab v2.1 在 v2.0 工作台之上，证明：

> 经过质量评测的真实语言模型，可在无静默回退、预算受限、规则验证与人工审批不变的条件下，完成至少两轮「读结果 → 规划 → 审查 → 执行 → 反馈 → 再规划」，并产出可离线复现与审计的证据。

**不应描述为：** 完全自主科研；自动生成源码 Diff；自动批准 / 自动 push；已完成 CUDA+DFINE 强验收。
