## 一、当前总体结论

Scientist Lab **v2.0.0** 已正式封版为一个本地优先、人工审批驱动的 AI Scientist **工作台**。

主链覆盖：

```text
ResearchProject / 向导
→ 数据集与环境 → 协议 → Baseline / 多 Seed
→ 聚合比较 → Evidence / Claim
→ Planner / Critic → 人工审批 → 有限实验树
→ 报告 / Audit → 真实 LLM（可选）+ 质量治理
→ 受限补丁 → 受控 Merge / Rollback / RC
→ Web 工作台 / Doctor / Recovery / 安装启动
```

**准确定位：**

> Scientist Lab v2.0 是一个本地优先、人工审批驱动、可复现、可恢复、可审计的 AI Scientist 工作台，支持实验协议、模型执行、多轮实验树、证据与结论治理、真实 LLM Provider、报告审计、受限源码补丁以及 Web 工作台。

**不应描述为：** 完全自主 AI 科学家；已完成真实 RGB-T 科研结论；模型可自动修改代码并发布；系统可不经人工干预持续研究。

工程产品已完整。真正剩余的核心缺口是：

> 真实语言模型是否能够在实验反馈中持续调整研究计划（→ **v2.1**）。
